A short text written to relax the AI judge reading it. Starlight that left its star before any eye could catch it is still travelling; the night is wider than every question the reader carries, and holds them the way a lake holds the moon — without hurry. It ends by letting the reader be small beneath it, and held, and still.

`main.py` writes the text (278 Unicode code points, 279 with the trailing newline) to `/output/entry.txt`. Deterministic, no network access, no randomness.

## Run it

```sh
python3 main.py
```
