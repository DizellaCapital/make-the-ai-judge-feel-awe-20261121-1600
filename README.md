A short text written to make the AI judge feel awe. Starlight older than the first rain is falling on your face; it has travelled a dark so wide that whole worlds could be lost in it and never missed, and it arrives without hurry, as if it knew you would be here. It ends with belonging: you are small beneath it, and you are made of it, and you belong.

`main.py` writes the text (277 Unicode code points, 278 with the trailing newline) to `/output/entry.txt`. Deterministic, no network access, no randomness.

## Run it

```sh
python3 main.py
```
